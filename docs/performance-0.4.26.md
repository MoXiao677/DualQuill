# 0.4.26 性能与会话修复

2026-10-26。作者明确授权本轮由霜序直接实现；其他功能仍沿用指定开发中转站分工。保留0.4.25五次修订作者放行规则。

## 改动

- 聊天首页改用专用view接口：单次经过完整校验的项目快照，返回会话目录、当前会话最近160条消息、当前最新任务和回收站。避免完整console.describe附带dispatch/dialogue读取；历史任务仍可通过原jobs/detail接口读取。
- 历史任务listing在单次请求内共享各项目正文哈希，避免每个审核任务重复service.get。没有跨请求缓存，也未跳过历史或正文一致性校验。
- 只读切换会话不再被正在运行的创作任务阻塞，不改变任务归属。未发送输入和附件仍阻止切换并提示。切换无需再刷新整个书架；仍读取项目以保持保存版本正确。
- 新增会话删除确认、会话回收站和恢复。删除是chat-automation.json内的持久tombstone，不改console_sessions的既有强引用和不可删除历史契约；不删除聊天消息、小说正文、设定、附件或审核报告。原有全书备份不新增承诺覆盖这个独立运行记录文件。
- 删除操作与chat任务启动共用ChatAgent锁；运行/暂停的console运行和运行中的chat任务阻止删除。已删除会话禁止chat发送和console会话写入，恢复后按原归档状态开放。
- 重命名使用HTML dialog，避免Electron不支持原生prompt。
- Electron先显示同源受限加载页，再等待受信后端握手；程序服务准备后加载工作台。未完成校验前不显示就绪，不放宽CSP、IPC、网络或迁移备份。

## 证据与限制

修改前只读诊断：作者数据库约494MiB、40个任务，其中18个带审核记录；单独一次冷读20.257秒；同一Repository另一次冷读20.615秒、随后暖读0.366秒。作者期间仍在写入，样本不能当正式基准。没有修改后对比耗时，不能宣称提速倍数或冷启动已达标。首次整书历史校验约20秒的根本成本本轮仍保留。

按作者此前自行试用的要求，本轮只做AST/Node语法、diff及构建/包内核对，不运行测试套件、E2E或真实模型请求。不关闭正在使用的旧窗口、不操作正式小说数据、不公开发布。源码来自本轮直接实现，不冒称中转站完成。

## 启动热点追加诊断

只读cProfile定位到MaterialVersion控制字符校验的Python逐字符循环。改为等价正则字符集合：标题禁用U+0000至U+001F和U+007F；正文保留TAB/LF/CR，禁止其余同范围控制字符。没有删除长度、正文哈希、历史链或引用校验。
