界面的 API Base URL、API Key、模型 ID 和“测试连接”均标明未来能力并禁用。页面不接收/存储凭据，不显示环境变量值；不能宣称配置中心已实现安全存储。S4 实施时建立后端凭据引用与配置边界，禁止明文浏览器存储或以日志替代秘密存储；系统凭据及 Electron 桥接继续依对应阶段方案实现。

## 2. 接入前的代码与协议验收

1. 按当时授权的供应商和实际协议核对官方文档，定义 `ProviderAdapter` 能力、参数、错误、流式事件、用量和取消契约。Base URL、模型 ID 与凭据引用分别管理；地址中的凭据或敏感查询不能进日志、导出或报告。
2. 连接测试由后端受控端点触发，保持本机边界及来源/token 检查。离线模式或未授权状态下拒绝外发；不在页面载入、选模型、保存配置时自动测试或发现模型。
3. 采用受控后端环境变量/凭据服务。密钥不进入渲染器响应、正文库、localStorage/sessionStorage、项目备份、截图、Git、异常堆栈或诊断包。凭据存储失败明确拒绝，不能降级明文。具体实现需在 S4 契约中评审。
4. 建立可取消任务与冻结的输入上下文，记录项目/实体 ID、输入 revision、供应商/模型、预算和任务来源。长调用不能复用当前短本机请求的全局 `busy` 锁住作者写作。
5. 生成结果保存为候选，预览、修改、插入和采纳分开。正式正文、过期候选和跨项目操作继续经过原确认、revision 与事务保护；发送按钮解禁不等于 AI 创作实现。

## 3. 本地协议夹具与业务回归（先完成，不消耗额度）

| 场景 | 可观察验收 |
|---|---|
| 连接参数与协议 | Base URL、模型 ID、协议和参数校验；不支持能力明确拒绝；两个连接独立；不静默换供应商 |
| 身份/模型错误 | 401/403、无效或过期凭据、未知/下线模型、404/422 均有脱敏分类；失败不写正文 |
| 超时/网络/服务失败 | 连接与响应超时、断流、DNS/TLS、429、5xx、畸形 JSON/流；任务退出等待状态，草稿和部分候选保留且状态真实 |
| 重试 | 有次数/退避/总时间与费用边界；认证/参数错误不无效重试；结果不确定时不盲目重复收费；记录每次尝试及可能的额外费用 |
| 流式与取消 | UTF-8 分块、缺失 usage、取消/完成竞态、重复点击、关闭窗口、重启中断；停止本地接收并按供应商能力取消，不能确认远端终止时说明可能继续计费；禁止伪造完成/用量 |
| 上下文与正文保护 | 小说 A 不读取 B；冻结输入后章节保存使候选过期；未保存草稿需明确纳入；采纳失败事务回滚，原历史不可改写 |
| 密钥泄漏 | 用虚构哨兵值检查渲染器响应、持久存储、应用日志、异常、导出/诊断、截图、测试报告及 Git 差异；任何泄漏为阻断项 |

夹具只能证明客户端/任务错误处理，不能替代真实供应商连接和模型行为验收。故障不容易在真实供应商稳定复现时，应分别记录真实结果及夹具覆盖，不能把夹具成功写成真实测试成功。

## 4. 经明确授权后的低成本真实测试

真实测试前向作者说明供应商、Base URL、协议、模型、虚构外发文本、请求次数/输出上限、可能产生的费用和金额上限；作者明确配置并授权后才执行。密钥由受控后端读取，作者无需在对话或测试报告中提供密钥正文。未知价格须先确认来源，不能承诺免费。

| 必测项目 | 通过标准 |
|---|---|
| 连接测试 | 真实供应商响应确认身份/模型可用性；请求是否计费、访问权限和日期明确；不假设 list-models 成功等于生成成功 |
| 简单文本生成 | 短虚构输入有真实返回、模型/请求标识及可获得的 usage；正文库不自动写入 |
| 续写或润色 | 用短虚构章和明确上下文生成候选；可预览、编辑、插入及拒绝；明确采纳才追加正式版本 |
| 超时与错误处理 | 短时限与受控中断有真实失败记录；难复现错误补夹具证据；输入不丢、不会无限等待 |
| 无效密钥 | 使用明确无效的测试凭据取得真实拒绝；错误脱敏，不覆盖作者有效凭据 |
| 模型不可用 | 指定不存在/无权限的测试模型取得真实拒绝；不擅自切换到收费备用模型 |
| 重试机制 | 安全可复现的临时故障验证有界重试，或记录真实触发缺口并保留夹具证据；不强行制造重复计费 |
| 密钥泄漏检查 | 上述所有路径完成哨兵扫描及实际脱敏证据核查；截图和报告只包含安全状态 |

报告逐项记录“通过 / 失败 / 未测试”、日期、实际供应商/模型、测试类别、耗时、次数、usage/费用依据与限制；没有 usage 不编造 token 数。失败先修复和复验；不能因 UI 或夹具通过宣称 AI 创作已验收。
