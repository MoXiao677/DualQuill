# 0.4.4：长请求与空书直接导入

自然创作对话的本轮总时限现在直接显示在输入区，可编辑；初稿、续写、整章改写和模型审核准备页也提供可编辑时限。新建这些界面输入默认 120000 毫秒，接受整数 100–300000 毫秒（最多五分钟）。冻结后的自然对话显示确切时限及候选字符上限；正文冻结详情保留确切 parameters.timeout_ms。重用历史输入时保持原任务时限，不把旧任务改成新默认值。

时限从作者单次确认开始执行时计算，覆盖连接、响应头和响应体读取；没有自动重试。窗口重开不继承旧进程执行许可，不会自动重新发送。增加时间不增加输出 token 或候选字符预算；自然对话仍固定最多 50000 字符，正文使用作者冻结的既有字符上限。模型输出仍只成为候选，正式大纲与正文采用仍须原有预览和明确确认。

Windows 下仅从另一线程 shutdown 套接字不足以可靠终止等待响应头的阻塞读取。共享 HTTP 传输现对已发送请求的读阶段使用非阻塞 socket 和最多 20ms 的 select 检查，同时检查取消事件与原始截止时间；TLS 读/写等待也使用同一截止时间。不缩短长请求，不反复重建连接，不改用假时钟。迟到响应不可产生候选或正式写入。

## V30 的准确范围

只在显式写入含 timeout_ms > 30000 的结构化记录时升级到 V30；读旧工作区不升级，旧请求正文、时限及摘要不重写。V29 及更早夹带长时限拒绝校验。完整备份、恢复、复制及能力目录支持 V1–V30；复制保持冻结请求正文、连接目的地和时限，原有 ID 重映射及重开许可边界保持。

此轮放开书级任务、共享正文任务和模型审核的时限。工作流模板、场景扩写、风格试写、检索等各自领域的旧时限与可分享格式没有统一放宽；不宣称所有生成入口均已支持五分钟。原生请求配置仍只在自建连接管理中声明，内建连接不接受此项管理操作；已保存配置在冻结前解析，冲突或模型覆盖明确拒绝。

## 空书导入

正文页在尚无章节时直接显示「TXT/MD 导入与导出」，无需创建占位章。仍走原有预览、条目映射和明确确认，不在进入页面时写入。首标题前原文作为独立前言保留，5 MiB 原文件和含前言最多 500 条、12 MiB HTTP 请求上限不变；大文件使用紧凑范围映射提交。
