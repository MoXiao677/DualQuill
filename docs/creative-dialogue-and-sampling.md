# 0.4.2：自然创作对话、采样参数与长篇保存

本次为本地开发交付，不是全部 C01–C18 完成声明。模型传输测试均为本机虚构供应商，真实调用、价格及文笔效果未验。

## 实际操作

1. 创建或打开小说，在「创作对话」新建会话，直接输入「帮我写一份灯塔悬疑小说大纲」。无需手建七步方案或编辑结构化操作计划。
2. 配置本次模型、输出 token 和风险预算，明确允许费用未知，然后「保存需求并冻结本轮请求」。先保存作者输入；未配置、离线或配置失效时不发送，需求保留。冻结请求展示完整历史、当前候选计划、正式大纲/世界观和锁字段，不自动加入未保存正文。
3. 核对完整外发请求并勾选本轮确认，点击「单次确认发送」。模型返回可读回复与完整大纲候选。再输入「主角改女主、扩成三卷」，新请求包含上一轮候选；不自动重发或继承许可。
4. 满意后「将本轮候选转为提案并预览影响」：先保存独立方案版本，预览具体新建/复用卷章与人物、锁冲突及确认章标题影响。此时正式资料仍未变。勾选正式确认后才应用。新章正文为空，已有正文和版本保留；没有自动工具执行。
5. 会话、作者要求、原始响应、候选、提案与收据随书持久化。关闭重开优先显示最近更新会话；旧冻结任务失去当前进程许可，须显式新准备。取消/超时/失败不自动续跑，不把部分输出写正文。默认每会话最多10次尝试/81920保留输出token；已选预设可进一步收紧，取消和失败不退回尝试额度。

## top_p / seed / stop

用途预设及正文、审核、细纲、扩写、书级规划、创作对话、文风分析、试写、搜索、比较和工作流入口提供可选参数。空白省略，明确填写才进入冻结配置和实际请求。top_p 为0–1有限数字；seed 为本应用保守的32位整数；stop 最多四条，每条1–200字符。不自动假定任何模型支持。

设置的逐连接管理提供「当前模型采样支持声明」。作者先核对原生契约，再声明明确支持；默认未知，未声明拒绝冻结，覆盖为其它模型不继承，重新保存连接后须重新声明。声明变化使旧冻结请求过期。此声明不是软件替供应商认证能力。

- Chat Completions：原生 `top_p / seed / stop`。
- Messages：原生 `top_p / stop_sequences`；seed 明确拒绝。填写 top_p 时切换到 top_p 模式，不发送 temperature；界面明确说明。`stop_sequence` 正常结束可形成完整候选。
- Gemini：原生 `generationConfig.topP / seed / stopSequences`。

seed 不保证确定性；停止序列通常不包含在返回正文里。本地只验证映射、门禁和候选分离；真实模型支持与供应商计费仍未知。本会话直接在线工具未取得返回；父独立验收于2026-10-20成功核对官方Claude、Google和OpenAI文档，确认新模型温度/top_p及Chat输出token字段有兼容限制。0.4.2未提供省略温度或max_completion_tokens选择，须继续实现显式逐模型请求配置，不能据本机映射测试声称所有真实模型可用。

## 数据兼容

首次写入采样或全书对话使用 workspace V28；没有新增顶层集合，复用现有会话、BookAI冻结任务/候选和方案链。完整备份、恢复、复制支持V1–V28；复制重映射会话任务引用，保留原冻结请求字节和原始响应，不继承执行许可。

旧采样缺省字段只在解析时提供类型默认，不插入已有原始记录，不改旧请求摘要；显式 `sampling:null` 拒绝。含采样的可分享创作预设使用格式2，无采样继续格式1；格式1夹带新参数拒绝。旧扩展模板格式1不能完整表达采样预设时明确拒绝导出，避免静默丢参数。

## 保存性能与完整性

历史校验改为带界限的内存前缀缓存。每次仍读取每条快照原始payload并计算SHA-256，同时核对revision、保存时间、当前payload和元信息；只有逐字节相同的已验证前缀复用昂贵解析/领域校验。外部改动、同大小/恢复mtime、历史缺失或坏JSON会失效并重新严格验证。缓存返回值隔离；失败事务不把未来状态加入缓存；磁盘历史完整保留。最多保留四本书的校验器。

本地虚构200章×5000字、4卷、12次真实保存：本次各次0.92–1.26秒，第12次1.22秒；之前独立0.4.1同规模第12次约6.48秒。重开2.75秒、完整备份8.05秒、恢复8.39秒、复制21.76秒；这些是本机临时数据的观察值，不是跨机器性能保证。外部完整性10项及本仓回归继续检验历史不可变、另一实例写入、陈旧revision、回滚、同stat篡改和返回值隔离。
