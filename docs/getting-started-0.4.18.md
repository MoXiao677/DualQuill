# DualQuill 0.4.18 上手说明

## 安装与数据

从 GitHub Releases 下载 Windows x64 ZIP，解压整个目录后运行 DualQuill.exe；也可下载安装器。程序自带运行时，无需另装 Python 或 Node.js。安装器未签名。不要只复制 EXE，resources 等目录必须保留。

发布包不含作者的 API、小说、数据库或附件。首次启动创建用户自己的数据目录；Windows 数据默认位于 %APPDATA%/DualQuill。升级前备份自己的数据，不要用旧版本程序打开新版本资料。源码启动使用 Python 3.11+：python run.py --enable-model-generation。

## 配置 API

在模型 / API 中心或聊天的写作 API 设置填写自己的服务地址、密钥、完整模型编号，保存后选择为写作连接。地址和模型编号由 API 服务提供，软件不提供额度。根据服务实际协议选择自动、Chat Completions 或 Responses。

再添加一条已启用的审核连接，在独立审核中选择并保存。写作与审核使用不同连接 ID，可以来自同一供应商；不要依赖作者的连接名称。生成章节或审核正文前需要有效的独立审核连接。首次发送如页面要求本次会话使用模型许可，请明确启用。保存配置本身不会发送生成请求。

## 聊天创作

创建一本自己的书后，在创作对话输入要求，例如“建立一本都市创业小说，先保存人物、世界观和十章大纲，暂不写正文”。上传 TXT、MD、DOCX、PDF，或填写本机文件/文件夹绝对路径导入。文件解析在本机执行；点击发送后，所选文本才会发送给 API 自动分类。扫描图片 PDF 尚无 OCR。

资料与正文统计不同：完成操作数包含人物、大纲、设定与清理；生成/保存/审核计数仅指本轮正文章节，资料保存成功时正文计数仍可为零。实际保存回执和模块中的内容才是依据。

正文生成后保存为版本，再由独立审核连接审核。严重问题最多自动修订两次；接口失败、审核证据不合规或仍不通过时停止，不假装通过。报告在资料库保留；正文变化后旧报告会过期。生成会有额外审核与修订调用，费用由用户的 API 服务决定。

可通过聊天维护人物、世界观、细纲、正文及记忆；删除后保留历史或回收记录，永久清除须谨慎。Enter 发送，Shift+Enter 换行。导出正文可选整本、分卷或单章，包含已保存正文。

## 已知边界与验证

上下文按当前章节、相邻正文、人物和已有记忆选择，并不把整部长篇永远全部发送；超出请求大小会停止。文件导入仍有单文件 8 MiB、所选总文本 120000 字符等限制。附件原件需单独备份，文档备份不包含全部原件。

本版通过 Python/JavaScript 语法、Windows 打包和作者现有资料启动检查。独立审核完整付费流程、任意供应商兼容性、干净 Windows 安装/升级/卸载未完成验收。此前写作流程已有实际使用，但不能据此保证所有 API 和所有长篇情形。
