## 使用与存储

点击首页模型按钮或菜单“模型 / API 中心”。三个站点独立显示配置及上次目录检查结果；密钥密码框始终为空，留空保存保留原密钥。修改后先“保存配置”，再“测试连接”；模型输入框可选择对应列表。

整个配置使用当前 Windows 用户 DPAPI 加密保存到 `%LOCALAPPDATA%/AI-Novel-Writer/providers.dpapi`，原子替换；加密失败不落明文。由后端读取，GET、保存与检查返回的只有安全元数据，页面不持久化密钥。此文件不包含小说，不属于 JSON 导出，不写入 Git；换机器/系统账户后须重新配置密钥。其他系统仍可离线使用，当前没有非 Windows 凭据保存实现。

HTTP 保持 127.0.0.1、Host/Origin/token 与原 CSP。新增受控 `/api/providers/save` 和 `/api/providers/test`；站点地址按连接固定，不接受登录页、任意主机或敏感 URL；供应商请求拒绝重定向，认证仅在 HTTPS 后端请求头中使用。原始错误正文不返回页面/日志。测试不使用全页面 busy 锁，响应限制 1 MiB、网络超时 15 秒，无自动重试或备用站点切换。
