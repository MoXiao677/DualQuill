# 2026-10-29 响应校验诊断修复

Chat Completions 原先将非 stop 的结束原因与工具调用合并为同一错误，无法判断供应商截断、过滤或工具调用。现通过独立校验函数保留安全白名单中的 finish_reason，并分别指出未授权工具；同时拒绝旧式 function_call，不接受截断正文，不记录原始响应或凭据。

实现与回归由已配置开发中转站生成，本地审阅整合。8 项响应测试与14项后台任务测试通过；源码语法与目录构建通过。安装目录269个后端资源与本次构建逐一哈希相符，更新资源清单，保留更新前文件备份。

真实流程：同一写作连接小请求 HTTP200、finish_reason=stop；第11章补审实际 passed=true。该验证不代表后续章节已创作完成，也不证明此前每次失败都是同一结束原因。续写采用紧凑规划、每批一个动作，避免一次输出大量章节计划。
