## 作者入口

1. 设置中默认完全手动。明确启用本次会话后，可填写自建供应商名称、API地址、已实现的协议、密钥和模型编号。保存使用当前Windows账户DPAPI，不发送模型请求。原三站旧连接继续保留；其他地址请添加自建连接。
2. 已实现Chat Completions兼容、Anthropic Messages和Gemini generateContent三种生成报文。只承诺声明协议，未知协议拒绝；真实供应商兼容性/语义质量尚未验收。公开端点要求HTTPS，localhost/127.0.0.1/::1的本机模型须明确允许；不跟随重定向，执行时校验DNS地址范围，DNS/连接/TLS共用绝对时限。显式本机模型可不填密钥。
3. 先选择一本书，在设置的“整套创作预设”分别绑定构思、大纲、正文、审核、润色、文风分析、试写和搜索配置，保存正文语言、作者文风提示词与预算偏好。保存新版本保留旧版本；明确采用一个版本才影响后续表单默认值，不生成、不改正文，也不授权外发。
4. 已采用的润色/审核配置会带入原模型任务；工作流写作/审核角色与运行限额也可带入预设。竞技场和工作流可直接选择自建连接。准备后须核对冻结正文、协议、配置版本、实际去向和请求摘要，再逐请求确认。费用未知不当0，风险预算不是美元硬封顶。
5. 本机跨书复用保留配置偏好；可分享纯数据导出会清除本机连接和风格ID，排除密钥、私有会话与运行数据。导入后缺失项明确提示补配，不自动换成其他模型。虚构示例见examples/creation-preset.json。

已保存配置的URL、协议、模型或密钥变更会产生新版本。新任务摘要绑定不含密钥的确切目的地；旧确认不能把正文发到修改后的去向，须重新准备。旧V1–V8行/历史不重写，旧三连接执行仍核对其固定地址与模型。V9增加正式目的地快照，V10增加creation_presets及creation_preset_choices；SQL三表/user_version1和document1不变，完整备份/恢复/复制包含新对象及历史，模型凭据不进入书库或备份。
