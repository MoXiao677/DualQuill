# 资料维护模型分配

聊天创作中只有正文生成（writer）和正文修订（revision）使用写作连接。理解指令、安排步骤、细纲规划、独立审核、剧情摘要、人物状态、世界观整理及其他非正文请求，统一使用当前任务冻结的独立审核连接。

本机审核连接配置为 DeepSeek，因此资料整理也由 DeepSeek 执行。其他用户仍使用自己配置的独立审核连接，不内置供应商名称或凭据。格式校验重试继续使用同一审核连接，不回退到写作连接。

已发出的请求不改变去向。正在运行的后台需要重新加载后，后续资料维护才能使用此分配。

资料维护输出容量调整为 12000 tokens，容纳完整 JSON 和人物合并资料。仍严格拒绝被截断的响应，不将不完整内容写入资料。
