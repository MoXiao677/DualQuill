# 0.4.21 本地候选：聊天会话与界面

日期：2026-10-26。基线为 main / f234490 / 0.4.20。本记录不代表公开发布，也不代表下一版清单全部完成。

## 当前变更

- 自动创作入口接收明确的会话 ID，校验其属于本书且未归档；原先未传会话 ID 的调用保持兼容。
- 聊天页提供新建、切换、重命名、归档和恢复会话；消息及任务按会话 ID 筛选，同书设定仍通过原业务上下文共享。
- 未发送文字、待处理附件或运行任务存在时阻止会话切换，并保留输入。此版尚未实现任意会话之间自由切换的独立草稿缓存。
- 输入区展示真实已保存的写作和审核连接，分别保存选择，不修改供应商地址或凭据；两者相同时明确拒绝。
- 输入区下方提供当前小说选择与单独的创建小说入口。
- 首页采用深灰底色、方块矢量 DualQuill 字标和居中输入区；会话页保留底部输入区。执行与审核详情默认折叠，错误和删除确认保留入口。
- 本地路径导入收进折叠项，移除状态面板的费用汇总展示。其他模块的费用文案尚未全面审计，不能称全局费用展示已全部撤除。
- 显式发送重试保留操作编号及冻结请求，避免因重新构造版本号造成同编号请求冲突；不会自动重发模型请求。

## 来源与数据边界

功能、界面及回归测试内容来自用户指定开发 API，真实调用经本地黑底 CMD 桥执行。协调者负责审查、受限动作集成、行尾和版本同步、验证与构建。部分 API 响应的外层 JSON 括号不完整，完整参数经受限恢复后执行；失败与原始返回保存在仓库外，不作为成功记录覆盖。
