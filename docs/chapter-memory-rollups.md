# 0.4.5：章节独立记忆汇总与本机连接兼容

## 章节范围

长篇记忆页的汇总范围新增「独立单章（仅此章有效位置）」。继续使用原有预览、显式保存、显式重建接口：`scope="chapter"`、`scope_volume_number=null`、`through_chapter_id=目标章ID`。它汇集作者已确认、当前启用、原来源未过期的记忆原文，不调用模型，也不是语义摘要。

每条记忆的有效位置取声明章节和来源章节中较晚的位置；只有有效位置恰等目标章的记忆进入单章汇总，前章和未来章均排除。来源位置在未来的条目即使声明本章也不能进入；目标章和相关来源章归档/在回收站时拒绝目标或排除来源。单章不接受分卷号，不接受其它书/缺失章节。

预览不落盘，不升级工作区；保存和重建沿用 operation_id 幂等、workspace revision / rollup revision 保护及冲突阻止。相同分类/人物/分卷/有效位置/标题而正文不同会阻止保存，作者必须修改或归档冲突记忆；系统不自动合并。

## 正文来源与历史

新单章汇总冻结 `chapter_source`，使用已有 MemorySource 结构，记录本书/章节、已保存版本、正文来源指纹和当时修订号。即使没有可用记忆、汇总正文为空，目标正文改变也会派生过期；只改未来章不会误报。原记忆/记忆来源改变、归档或新确认记忆也按既有来源集合检查派生过期。没有自动重建或自动把正文当作记忆。

归档或移入回收站的目标汇总继续可读，列表 `stale=true`、`available=false` 并返回 `unavailable_reason`，UI 禁用重建并解释须先恢复。恢复后才可重新预览/重建。显式重建追加汇总历史，不修改前版；UI 可展开不可变汇总历史与确切章节来源。

首次保存单章汇总升级 workspace V31。旧书/卷汇总的 `chapter_source` 编码省略，原 V23 记录、原 history 和旧 SQLite 快照逐字保留；不会读时升级。V30 及更早夹带单章结构拒绝。完整备份恢复复制支持 V1–V31；复制映射汇总、历史、目标章、chapter_source 的本书/章节/版本，以及每条原记忆来源，保持原文与指纹及已有许可边界。

## 旧章节 ID 与 localhost 修复

旧 V1 书中的章节实体编号允许非 UUID。归档/回收站事件此前错误地对 chapter_id 调用 UUID 校验；现在按已有实体引用契约接受非空章节编号，仍由完整状态校验保证属于当前书。新事件 ID、操作 ID 及事件链接继续要求 UUID；未知/跨书引用拒绝。旧 V1 备份恢复后归档、恢复、回收站、恢复原章及再次重开均有回归测试，不改写原章节或旧事件。

localhost 在 Windows 可能先解析 ::1、后解析 127.0.0.1。0.4.4 只尝试首地址，导致仅监听 IPv4 的合法本机供应商在发送前失败；0.4.5 在全部解析地址先通过原 SSRF 校验后，允许 TCP 建连失败时尝试其余已验证地址，统一总截止时间不重置，每个失败 socket 关闭。DNS/连接取消、TLS 证书校验和允许 loopback 的显式开关保持；只有 HTTP POST 发送前的 TCP 地址切换，收到 HTTP 错误或已发送后不重试。

## 验证边界与后续

本轮验证使用旧 V1 虚构夹具、新临时书库、随机 loopback 端口、虚构凭据和隐藏桌面。父独立源码已验证精确章范围、原快照/书卷历史、正文过期/非本章不误报、冲突幂等、旧章归档、V31恢复复制/HTTP与桌面实际确认；最终包及全量结果另见最终验收记录。

仍未实现模型语义摘要、记忆自动提取/更新、汇总自动进入上下文或 SSE。下一切片计划为作者明确启用后的已保存汇总上下文消费，须先完成本版全量与固定产物，再修改下版源码。真实供应商效果、费用、干净 VM 安装升级卸载、签名与发布没有冒称通过。
