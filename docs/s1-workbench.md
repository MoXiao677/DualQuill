# S1 工作台行为规格

> 本文保留原 S1 编辑器布局规格；作者随后确认的最新默认对话首页与模块收纳见 [对话工作台规格与验收](chat-workbench.md)。原保存/草稿/历史保护仍适用。

2026-10-13：作者已确认实施。沿用 Python/SQLite/原生 textarea，不修改业务动作和数据格式。

## 视图与对象

- 左侧固定活动栏：章节写作、项目资料、全书大纲、人物设定、世界观、文风规则、Skills、指南、模块规划、设置。书架与章节树位于独立导航面板；章节按原 number 顺序，标题过滤只作用于已加载章节。
- 中央：按项目 ID、视图、章节/人物 ID、正文/IDEA/细纲区分文档标签。正文区域优先占据空间，编辑表单继续提交已有业务动作。
- 右侧：已保存的人物、世界观、历史原文和只读差异；可跳转实际编辑器。记忆显示后续阶段状态。历史比较不写库，恢复追加新草稿，正式章继续明确授权。
- 底部：本窗口真实读写/错误活动，不记录正文和请求字段。智能控制台显示当前项目/章节/选区范围，AI 对话、模型、工作流保持禁用并说明阶段。
- 状态栏：离线/手动模式、保存状态、当前编辑区字数与选区。Ctrl+S 保存当前表单，Ctrl+K 打开可过滤命令；输入法合成中不触发保存。

## 草稿与并发

草稿只在窗口内存中，按实体隔离，导航不要求丢弃。关闭未保存标签需要确认；刷新/离开窗口在任一草稿或写入处理中提醒。布局、宽度、明暗主题只写浏览器偏好，正文不写 localStorage/sessionStorage。

每份草稿绑定开始编辑的 revision；重读外部新版本不能静默重新绑定。显示已保存值与草稿供逐项比较，明确确认后才允许以最新 revision 保存。自己的成功写入可推进同一旧 revision 上的其它草稿，已经过期的草稿继续过期。失败和冲突保留输入；写入成功而书架刷新失败报告已保存，避免重复创建。

## 布局与验收

左右面板和底部面板可折叠；左右分隔条可拖动和键盘调宽。专注模式临时隐藏面板，退出恢复；窄屏为可关闭抽屉，打开时移入焦点，关闭恢复焦点。页面不横向溢出，各区域独立滚动。

目标视口为 1440×900、1280×720、1024×768、390×844；100 章虚构资料测量已加载章节切换 <300ms。验收复用真实临时数据库，覆盖保存/重启、原文空行、正式章授权、恢复、双窗口冲突、刷新失败、Skills 安全和中文 IME。
