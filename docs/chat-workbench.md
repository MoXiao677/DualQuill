## 1. 范围与结构

首次打开显示近黑色 `#080808` 的对话准备首页，输入框 `#171717`。首页无手动文档标签，模块导航默认隐藏、按需打开菜单；手动工作区保留按项目/模块组织的文档标签，底部输入框位于独立滚动区之外。书架/章节树、右侧上下文和任务区不在首页默认展开；作者显式打开后显示真实资料或本窗口活动。窗口高度不足 600px 时首页活动以顶部临时浮层打开、通知限高滚动，保持输入与工具可达。手动编辑页继续使用既有真实表单、固定保存区和独立资料栏。

## 2. 需求输入与上下文边界

- 多行输入记录未发送需求，Enter 换行；发送和停止生成始终明确禁用，模型按钮打开真实状态与配置入口。
- 输入按项目稳定 ID 存于 `PromptStore` 内存。尚未绑定小说的输入有独立作用域；创建/切换项目后可以“查看未绑定需求”，回到当前小说需求，或经确认清空当前需求。不同小说不会继承别本或未绑定的输入。
- 上下文对话框只列当前小说的章节/人物；世界观可明确选择。保存稳定实体 ID 与复核 revision，不复制文本或发送内容。未保存编辑草稿不自动纳入，保存编号变化显示复核提醒；清除引用不改正文。
- 任一未发送文字与正文草稿触发 beforeunload 提醒。二者不落盘；关闭/刷新接受后会丢失。没有会话历史、候选、费用、模型回应或自动正文采纳功能。
- 原文档草稿、外部冲突、正式稿授权、追加历史和保存成功/页面刷新失败的区别保持。品牌首页现在在窗口内导航，实际刷新/关闭仍由浏览器保护。
