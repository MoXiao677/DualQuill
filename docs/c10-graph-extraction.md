# C10 图谱抽取、路径和交互

本增量在隔离副本实现，尚未由主工程整合或打包。工作区版本暂用 **V45**，最终编号由整合者分配；SQLite 表结构和 user_version 不变。

## 作者流程

1. 在「章节写作 → 图谱与反馈」明确选择截至章及 1–8 个已保存来源章节，包含截至章。来源必须属于本书、非空、未归档且未进回收站，不允许选择截至章之后的正文。
2. 选择连接、模型和预算，准备专用 `graph-extract-json-1` 请求。准备不发送；在模型任务页复核冻结请求并确认执行。只发送选中章节的已保存正文，不混入计划、记忆、未来章节或编辑器草稿。
3. 完成后返回图谱提案，逐条查看实体、别名、关系及精确引文。引文按 Unicode 码点验证来源编号、起止位置、原文、正文版本和 SHA-256；无引文、错引文、重复临时编号、未知关系端点均拒绝。
4. 模型输出始终是待核实提案，不自动生成正式图谱。作者勾选核实推断并接受后，在一个事务内生成整份正式实体与边；拒绝或取消不产生正式图谱。同一操作身份重试幂等，冲突拒绝。发送前、工作线程发送边界和采纳时均复核来源及连接。

## 图谱与查询

- SVG 可缩放、重置、滚轮缩放、背景平移和拖动节点；节点/边详情可导航到已保存出处版本及各条引文。键盘 Enter/Space 可打开详情。390px 窄屏提供同一套控件。
- 路径查询仅使用作者确认且来源新鲜的已保存事实，支持出向、入向、双向及关系白名单；深度 1–6、结果 1–50 条，最多 5000 次扩展，截断明确标记，路径不重复节点。
- 图谱按截至章过滤，所有引文及合并来源共同决定有效章位和过期状态，未来别名和合并元数据不进入较早章位。旧人工图谱、合并影响预览与恢复沿用 append-only 历史。
- 索引按正式实体/边历史增量派生，显式重建校验 revision，返回确定性摘要和数量；不修改正文、正式历史或 revision，不调用模型。缓存只在当前服务内存中存在，重开从保存历史恢复。

## 持久化与接口

V45 增加 `graph_extractions`、`graph_decisions` 两个 append-only 集合，提案绑定真实已完成任务和原始响应记录，状态校验重新验证模型原文。完整备份/恢复保留全部提案、引文、决定和正式图谱；复制显式重映射任务、响应、来源、决定和图谱身份。冻结请求正文及其绑定保持原样，恢复/复制不继承执行确认许可，不能自动重发。派生内存索引不进入备份，可本地重建。

接口前缀 `/api/projects/{project_id}/knowledge/`：`extract-prepare`、`extract-list`、`extract-decide`、`paths`、`rebuild-index` 均为 POST，遵守现有会话和同源校验。出处继续使用 `source`，支持提案引文。准备接口返回 HTTP 200。

## 验证边界

2026-10-21同库组合发现：已有书级规则时，图谱的只读来源准备未冻结规则依赖，却在发送时进入通用规则新鲜度守卫。现冻结适用规则的版本/SHA依赖，并在图谱发送及接受边界复核完整规则集合；规则正文仍不混入图谱请求，只发送明确选中的已保存正文。规则变化后须重新准备，不能以跳过守卫恢复执行。组合测试及原失败/后续结果位于本轮03项仓外证据，作者及真实模型质量验收另计。

测试仅用任务目录中的虚构 SQLite、虚构连接和随机 loopback 端口，真实供应商调用及费用为零。三种协议的 JSON 传输、引文、采纳、事务回滚、磁盘重开、完整备份/恢复/双次复制、未来/跨书/过期、取消和真实浏览器流程均有定向覆盖。旧格式覆盖分为冻结的真实虚构样本与所有 V1–V35 的空集合结构样本，不能将后者称作全部版本的历史业务数据验收。
