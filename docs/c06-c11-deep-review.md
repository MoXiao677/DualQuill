# C06 / C11 深层审核与本地语义重复提案

本入口只冻结作者明确选择的来源范围；任务级规则绑定尚不适用于深层审核，直接请求带该绑定会明确拒绝，不静默省略。普通正文/模型审核原任务规则链保持。

本切片在 0.4.13 白名单快照上新增 `deep-review-json-1`，复用保存正文模型审核的准备、逐次确认、预算声明、取消、超时、真实返回与报告持久化管线。旧 `review-json-1` 与工作流 `model_candidate_audit` 的请求和输出契约保持独立。当前新增工作区版本建议为 V41，最终整合时由主整合者统一分配；这不是产品发布版本。

## 作者操作

1. 打开已有「准备模型任务」页的「深层审核与语义查重」，明确选择正文及本书候选、资料、已确认记忆、规划来源。正文至少包含主章，最多 40 章；全体来源最多 80 项、20 万 Unicode 字符。
2. 选择相对时间、不确定时间、持续时间、因果、动机、人物知识边界、全书节奏、人物弧光、语义重复中的检查项目，并填写已保存连接、模型编号、输出上限、总时限与风险预算。费用未知时须明确认可未知风险。
3. 点击「冻结深层审核请求」只准备请求，不外发。转到原任务页，逐字核对确切请求和 SHA 后，单次确认执行。每一任务都需要新的确认；恢复、复制、重开不会继承内存执行许可。
4. 报告逐条显示待核实意见、完整冻结来源、来源身份与版本、Unicode 引文区间、实际返回与未知用量。可记录误报、豁免、重新打开及理由，所有处理追加保存。
5. 本页不提供正文采纳、自动改稿、确认记忆或生成图谱事实。作者应在原编辑/记忆工作流自行核实与明确保存。

## 来源与保守处理

- 正文只消费已保存当前版本；未保存输入不进入请求。当前有效正文全选才标记全书覆盖，部分选章显示实际覆盖章数。超过 40 章的书不能在本入口一次覆盖全书。
- 候选必须属于本书、有真实成功生产任务和 attempt、尚未采纳、生产依赖仍新鲜，并且不属于未揭晓比较。保留真实 task / attempt / workflow node 身份，候选 `version_id` 为 `null`。带全局 Skill 依赖的候选暂保守拒绝，提示使用原工作流候选审核入口。
- 资料必须显式选择，未归档且当前版本具有完整当前字面索引。索引缺失、过期或恢复归档后的资料须先在资料页显式重建。参考资料不变成故事确认事实。
- 记忆只接受当前启用、作者确认且来源未过期的记录。相互矛盾的已确认记忆保留双侧，不自动合并，也不推断哪条正确。
- 规划仅消费已有全书大纲、章节细纲、人物弧光及阶段、关键事件。保留作者登记的 planned / occurred 等状态和章位；计划不是发生，已登记发生仍需核对正文。此模块不依赖另一个未完成的图谱副本，也不新增图谱事实。
- 准备、开始和 worker 外发边界复核来源；任一来源正文、身份、版本、状态或有效全书章数变化，旧请求拒绝发送，须重新冻结与确认。

## 模型契约与证据

专用输入包含检查列表、限制、覆盖计数及冻结来源；各来源发送顺序编号、类型、事实地位、保存元数据、章位、原文和原文摘要。可重映射的本地实体 ID 不进入 wire，因此复制可以映射本地身份并逐字保留原请求与摘要。

输出只允许 `overview`、`findings`。每条 finding 只允许 `check`、`statement`、`assessment=model_opinion`、`status=unverified`、`evidence`；证据只允许 `source_index/start/end/quote`，按 Unicode code point 的左闭右开区间逐字验证。伪引文、UTF-16 偏移、未知字段、确认事实状态、自动修改内容或工具字段均拒绝，不生成报告。最多 40 条意见，每条 1–4 个证据；语义重复必须恰有不同来源或同源不重叠区间的双侧证据。

入库复用 `ModelAuditOutput`，意见前缀为 `[待核实/<check>]`，`proposals` 与 `bridges` 为空，报告 `quality_verified=false`。格式、传输与出处验证成功不代表语义判断正确；人物知识、因果、动机、节奏和弧光仍须作者判断。

时间辅助仅对保存的规划时间字段做有限完整字面匹配：第 N 天、日区间、ISO 日期以及显式锚点后的少量相对天数。无法解析、约数、缺失锚点、非法日期返回未知，绝不补 0 或采用系统日期。持续天数返回最小/最大区间；区间重叠不自动构成矛盾。该辅助不是从正文推断事件的语义规则引擎。

## 历史、存储与接口

- V41 新增 `deep_review_actions`，误报/豁免/重开追加保存。签名绑定检查类型、精确来源身份/版本、引文与区间；来源证据变化不继承旧豁免，原报告和处理仍可查看。
- 模型分析参数仅新请求携带可选 `deep_review`；旧记录省略该字段，不改旧冻结字节。V1–V35 普通只读不升级，新深层任务首次写入才升级；带新字段降级为旧版本拒绝。
- 完整备份/恢复支持 V41；复制映射 scope、证据、处理以及候选生产者的所有本地身份，并重算本地范围/处理签名，保留原外发请求和摘要。
- `POST /api/projects/{pid}/deep-reviews/prepare` 准备；`GET /api/projects/{pid}/deep-reviews/{report_id}` 只读报告；`POST .../{report_id}/decision` 追加处理。原模型报告 GET 也能展示深层报告。
- 写入口继续验证会话 token、严格字段、revision、operation/request 身份与幂等性。不存在/跨书报告返回 404；已被另一书认领的相同处理 ID 优先拒绝为 409。

## 实际验证边界

定向测试使用虚构小说、随机 loopback 端口和虚构凭据，覆盖三原生协议 JSON/SSE、双侧 Unicode、非法输出拒绝、HTTP、预算/每次确认/取消/超时/过期、资料边界、矛盾记忆、规划只读、误报豁免和恢复复制。另有 V1–V35 空功能集合生成样本的磁盘字节与 SQL 行只读保真，补充既有非空历史 fixture 回归，不能称每版真实复杂历史都已覆盖。

最终命令、退出码及原失败见任务目录 `verification.json` 和 `evidence`。未调用真实付费供应商；未做真实模型准确率、全网查重、任意长篇全书覆盖、桌面视觉/IME、全量、打包、签名或安装器验收。
