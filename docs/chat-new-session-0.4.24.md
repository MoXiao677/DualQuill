# 0.4.24 清屏 / 新会话

## 本次需求

在输入框旁提供明显的一键新聊天入口。清屏表示为同一本小说创建新的持久聊天会话并切换显示；保留旧聊天记录、任务记录和已保存小说资料。不删除正文、人物、世界观、大纲、规则、Skills 或附件库。旧的清空按钮更名为“清空输入”，仍只处理未发送输入。

新会话自动命名，不依赖桌面宿主可能不支持的浏览器 prompt。仍须等当前任务停止，并处理未发送草稿和待发送附件后再切换，避免丢失输入。按钮不发起付费模型请求。

## 当前上下文实现

- 每条作者消息创建独立任务；模型请求由本地组装，不依赖供应商隐藏会话或 previous_response_id。
- 各阶段读取当前本地有效资料并检查修订号；任务开始冻结所选 Skills，供任务内各阶段使用。
- 规划请求补充当前聊天会话最近六条历史，每条最多 1500 字符。写作、审核、修订和资料同步直接带本轮原始作者要求及各自阶段数据。
- 正文按目标章取当前章及前两章，加入全书大纲、目标细纲、世界观、有效规则、相关人物及有效记忆；不是每次读取全书正文。未来、隐藏、过期、停用或未确认记忆按现有规则排除。
- 参考资料先纳入元数据；实际正文通过 read_material 分页读取。资料元数据数量不等于实际读取页数。
- 新聊天不引用旧会话的聊天历史，仍读取同一本书已经保存的有效资料。只在旧聊天中提过、尚未保存到资料中的要求，不保证在新会话里延续。
- 请求上下文记录显示实际纳入的版本、范围、文件及哈希；不证明模型已经理解或遵守。
