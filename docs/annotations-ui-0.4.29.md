# 正文批注 UI 集成说明（0.4.29 工作项）

本工作项不修改应用版本，不添加依赖。后端接口以 annotations-backend-contract.md 为准。

## 已接入

- 章节写作旁新增独立“正文批注”导航；按项目、章节隔离窗口内草稿。
- 三栏章节列表、正文编辑器、批注/候选面板；窄容器或窄屏改为纵向堆叠。
- 正文输入原位更新保存、放弃及标注/采纳按钮，不替换正在输入的 textarea。未保存正文禁止标注、新建批注和采纳。
- 本地意见、手动候选、精确 Unicode 码点引文、差异预览，以及逐次准备/确认外发、独立审核、显式采纳、受保护撤销和提交结果核对。
- 纯函数导出 `annotationSelection(source, editorValue, start, end, action='selection')`，返回精确来源的 `{start,end,quote}`。先验证编辑区严格等于已保存来源仅将 CRLF/单独 CR 映射为 LF 的结果，段落边界按 `editor.value` 计算；再逐个来源 UTF-16 码元行走，将 CRLF 视为一个显示 LF，把 textarea UTF-16 边界映射回来源边界，最后转换为 Unicode 码点。支持 emoji 在选区之前及 CRLF/LF/单独 CR 混用；拒绝非整数、越界、倒置、截断代理对或编辑区/来源不一致的边界。整章保留精确来源，空的已保存章节允许 `0:0`。引文保留原始换行，SHA-256 和版本仍绑定未修改的已保存来源；不会为了批注规范化或保存正文，也不搜索引文或自动重定位。
- 主导航在章节写作旁显式渲染 annotations 按钮，高级列表排除此项，避免重复入口。
- 明确的 HTTP 4xx 拒绝清除待重送请求，但保留意见、正文和候选草稿。网络错误或 5xx 保留原路径和完整幂等 payload，仅由作者显式重送，绝不自动重试。
- 任务轮询结果未变化时不重绘；变化时保留脏文本、焦点/光标和当前勾选。离开或父视图重绘停止轮询，异步回调受项目、视图和 renderId 约束；workspace 回调不重绘其他视图。
- 隐藏准备预览按草稿内请求 SHA 生效，不代表取消后端请求；新准备仍须逐次明确确认。
- 浏览器关闭提示涵盖批注脏状态；桌面和 HTTP 静态资源白名单均加入 annotations.js，未放宽 CSP 或协议规则。

## 限制与交接

- 未保存正文、意见、候选和待重送请求仅在当前窗口内存中；关闭、刷新、崩溃不会恢复。离开页面不等于保存。
- 已保存批注元数据位于独立 .chapter-annotations.sqlite3 sidecar。独立 workspace JSON 导出、standalone 备份和项目编号重映射不包含它；需随完整小说库目录保留。专用导出/导入尚未实现。
- 模型仅支持后端允许的 JSON transport，不支持 SSE；非默认原生 token/温度配置会被拒绝。费用未知，准备不发送，候选不自动写入正文。
- 已确认章节修改仍需作者逐次授权，后端锁与来源版本校验保持有效。来源过期不会自动重定位；不确定正文提交通过显式核对恢复，不自动覆盖。
- 轮询最多本页 120 次；停止查询不代表停止后端任务。取消不退款、不撤销正文。中断任务不自动重启。
- 开发仅进行源代码阅读与集成修改；没有运行测试、run_checks、构建、浏览器/UI 验证或真实 provider 请求，未访问真实用户资料、凭据、小说、数据库或日志。协调者负责运行时验证、构建及发布前审查；不宣称真实模型质量或 UI 已验收。
