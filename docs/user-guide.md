# AI-Novel-Writer 使用指南

## 0.4.13 候选模型审核（有限本机验收已接受）

保存章节后，从章节页进入“工作流与人工节点”，点击“填入候选模型审核模板”。先预检、保存新模板，再为写作和审核分别选择已保存连接、模型及风险预算，创建独立运行。模板、预检、创建与单步准备均不发送模型请求；每个writer/reviewer请求都须核对冻结内容并单独确认。

写作完成只产生未采纳候选。审核只发送这个真实候选及其生产者身份/摘要，不发送正式正文或其他章资料；JSON/SSE完整完成且引文合法后生成“待核实模型意见”。流式文本只是转义的临时预览，取消、超时、断流不保留为报告。报告不能当成事实或质量保证，也不会自动新增记忆。

审核后仍须作者核对human节点的具体差异，再执行apply才写正文。正文、上游依赖或连接变化应重新准备，暂停/恢复、重开与复制不继承旧许可。V35完整恢复保留原历史，复制映射本地candidate/producer/response身份，并用typed映射链保留原外发身份与冻结请求。旧model_audit仍只接受已保存正文。准确契约和未验范围见[候选审核说明](candidate-model-review-contract.md)。

## 0.4.10 单章模型语义摘要

先保存本章正文，在“长篇记忆”页找到“单章模型语义摘要”。选择唯一章节和已保存连接，核对只读正文、模型、输出上限、时限与风险预算，再冻结请求。未保存输入、其他章节、计划和记忆正文不加入此请求。

冻结只保存任务，不会发送。任务页展示确切请求，勾选本次外发确认后才执行。连接可明确声明SSE；流式内容是临时预览，取消、超时、断流或不合法输出不生成提案。完整完成后打开报告，逐字核对本章引文；模型摘要仍可能不准确，须作者判断。

明确接受只新增记忆并保留原记忆与正文；不同记忆须明确保留冲突。来源正文、记忆集合或连接配置变化会使旧任务/提案过期，应重新准备。摘要进入已保存汇总仍要另行预览、保存或重建，不自动更新。V34备份恢复复制与准确验收进度见[摘要说明](semantic-summary-contract.md)。

## 0.4.2 自然创作对话与采样参数

打开一本小说并新建创作会话，直接输入「帮我写大纲」，再说「主角改女主、扩三卷」。每轮先保存需求/冻结完整历史与模型预算，再勾选确认发送；回复先是候选。满意后显式转提案、预览影响，勾选确认才写正式大纲/人物/卷章，已有正文保留。

设置里核对当前默认模型的原生能力后声明 top_p/seed/stop 支持；用途预设和本次覆盖可选，空白不发送，未知/不支持拒绝。Messages seed不支持，填写top_p不发温度；当前完整响应，未实现SSE增量。参数/配置变更使旧冻结任务失效。V28备份和格式2共享预设规则、完整操作与边界见[0.4.2交付](creative-dialogue-and-sampling.md)。

下文0.4.1及更早介绍为历史，以本节和准确交付为准。


## 0.4.1 新增入口

章节写作页提供跨卷移动/拖拽、位置选择和回收站；先预览引用影响，精确输入标题并确认后才移入回收站。恢复保留正文历史并回到原卷顺序。TXT/MD 自动严格检测 UTF-8/BOM，其次 GB18030，坏字节不替换；也可手工覆盖编码重新预览。

设置页提供逐连接启停、明确删除凭据、本进程请求间隔和每分钟上限、自建模型发现。配置变化后旧任务需重新准备。本地能力目录列来源/日期及未实现参数，真实价格未知；手工估算需自己提供 token 和单价，不是实际账单。

独立恢复完成后可用 PowerShell 打开恢复库：`& '解包目录\AI Novel Writer.exe' '--database=C:\绝对路径\恢复库.sqlite3' '--profile-dir=C:\绝对路径\独立配置目录'`。将示例路径替换为恢复提示的真实绝对路径，使用独立配置目录。当前工作台仍使用原库；备份不含密钥和未保存输入。最新本地验证及外部边界见[0.4.1 验收](final-local-0.4.1.md)。

2026-10-20更新。软件内“使用指南”使用相同中文内容。英文界面已由作者取消，正文语言与原始英中文内容保留。章节构思/细纲见[C04-B1交付](c04b1-chapter-planning.md)，场景/选区扩写见[C04-B2交付](c04b2-scene-expansion.md)，初稿/续写见[C04-A交付](c04a-chapter-writing.md)；整体缺口见[功能矩阵](current-feature-status.md)。当前为开发版，原作者预览不自动更新。

## 开始写作

默认完全手动，无需密钥。创建小说，或点击“从零构思新书”，逐步整理创意、读者、篇幅、冲突、人物世界、主支线与卷章。方案可以分支、返回修改和锁定。保存提案后，预览影响并明确确认，才创建正式卷章规划。

软件界面统一中文。正文语言由作者选择；英文小说、英文提示词、原始资料和模型响应均可原样保存。

## 正文与未保存输入

“章节写作”分别保存正文、IDEA和章节细纲。Ctrl+S保存当前文档并追加版本；确认章节的修改或恢复需要明确授权。大纲、人物、世界观和规则各有保存入口。

圆点和“未保存修改”表示当前窗口草稿。正文、IDEA、细纲等编辑输入会在本机应用数据目录自动保存，并在切页/失焦时立即落盘；崩溃或重开后显示“本地恢复草稿（未保存）”，基于旧保存编号时须显式对照后选择保留或放弃。保存成功、关闭标签或明确放弃会清除对应草稿。草稿不进备份/复制，也不是正式备份。

## 上下文、记忆与图谱

正文页可预览已保存上下文，明确选择正文范围、规划、人物、世界、规则和记忆。规划是创作意图，不是已发生事实。未来章节默认排除；自由资料可能含剧透，须作者判断。

记忆支持人工记录、出处、确认、纠正和归档。模型摘要/摘录先是提案，接受才成为记忆；来源变化后需要复核。图谱支持人工实体关系、别名合并与恢复、单字段规划反馈和局部正文提案。字面检索与离线规则审核不能当作完整语义推理。

## 模型与创作预设

在“设置”明确启用本次会话的模型，再配置供应商、已实现的协议、API地址、模型和密钥。密钥由Windows账户加密保存，留空可保留旧值。保存不请求模型；连接测试只获取模型列表，不发送小说。

创作预设独立绑定各步骤。预设是偏好，不是执行许可。每次请求须核对冻结输入、模型、去向、次数与输出上限，单独确认。费用未知不能当0，风险预算不保证美元硬封顶；取消也不能保证供应商尚未处理或计费。

## 模型任务与作者决定

在章节页可点“AI 章节构思”，选择 IDEA 构思或章节细纲/场景，明确选入本书人物与资料，预览实际输入后冻结并逐次确认。候选可人工修正，查看具体差异后才采纳为真实 IDEA 或细纲版本；模型不会写正文、创建人物或地点。正文中选好一段文字后点“AI 场景/选区扩写”，可按已采纳场景序号或精确选区扩写；场景在正文末尾插入，选区只替换选中码点范围，范围外原文保持。构思完成后回到章节页，空正文点击“写初稿”，已有正文点击“续写”，已采纳的 IDEA/细纲会进入真实请求。正文采用用途预设并可覆盖本次模型和参数；候选复核差异、明确采用后才追加正文版本；续写只编辑新增文字，保留原稿全部前缀。“模型任务”继续提供整章改写或模型审核；新书规划每一步也可请求AI辅助。准备和预览不外发。实际响应只读保留，失败/中断不自动重试。书级AI采用先成为规划提案，仍需原规划确认。

章节构思、场景/选区扩写、初稿/续写都不自动修改人物、正式规划或记忆事实；真正来源、版本、锁、文风或配置变化会阻止旧请求和旧采纳。目标字数、实际新增字数与偏离如实显示，字面规则命中仍须作者判断。模型意见和引文需要核实，本地技术验证不证明真实供应商可用性、文笔质量或账单。

## 文风资料、搜索与短试写

“文风规则”可粘贴/导入文章或整书TXT/MD，也可导入自己的提示词/风格卡。规则页还支持全局/本书/分卷/章节分级必写、禁写和风格指引；可查看某章实际生效规则与冲突，冲突未解决时不能准备任务。旧书级写作规则仍作 legacy 指引生效。原资料只读保留，分块提炼逐请求确认，编辑卡后保存版本并明确应用到书或章节，不自动改正文。

书名与平台搜索仅使用已支持的Gemini原生搜索能力。先确认作品身份和真实引用，再另行确认公共页面读取，核对来源、样本类型和字符区间后导入。简介、目录和片段不代表全文；读不到请自行导入，不绕过登录或付费。

短试写使用自己的设定、已保存文风版本或明确无卡基线，不自动发送提炼原资料。A/B使用相同设定，可比较文风或模型。每侧单独确认，先盲评分再揭晓；失败侧没有数字评分。打开只读候选后可明确选择对应文风，不把试写当作整章写进正文。

## 比较与工作流

章节同题比较冻结共同输入，两配置分别确认。评分是作者对该样本的判断，不是通用模型排名。选择胜者只打开候选或保存配置预设，正文仍需独立采用。

工作流保留模板和运行历史，支持单步、串行排队、人工节点、暂停取消与明确恢复。模板不授予外发或正式写入许可。每个模型请求、每项正式差异均须本次确认。失败可显式生成新结果重跑；恢复/复制不继承旧许可。

## 备份与迁移

“历史与恢复”查看正文版本和差异，恢复追加新版本。保存编号冲突后重新读取，对照最新内容与草稿，明确合并或绑定。真正保存失败保留输入；提示已保存但刷新失败时不要重复创建。

完整.nwbak包包含当前已实现对象的全部小说、资料、历史、Skills、文风和任务记录；排除API配置/密钥、会话许可和未保存输入。恢复到独立新目录，不覆盖当前库。导入/复制先预检报告，复制本使用独立新编号。断线后先核对原操作结果。JSON导出缺少完整库快照与全局Skills，不能替代完整备份。

文风TXT/MD资料导入与小说分章导入不同。小说章节页可上移/下移、软归档或恢复，并打开“TXT/MD 导入与导出”：先预览第X章/节、Chapter N 或 Markdown 标题映射，确认后追加章节与新卷；导出只含已保存内容，未保存草稿不会包含。

## 需求准备与快捷操作

“创作对话”按项目保存会话、消息和可编辑操作计划；可新建/改名/归档会话。计划步骤支持 IDEA、细纲、初稿、续写、场景/选区扩写。点击“派发准备”只会生成既有协调器的待确认任务，不会外发或执行；到任务页逐请求确认后才可运行，采纳仍需原入口。控制台显示任务/候选/收据回链，模型文本不会触发工具或写入。

Ctrl+K搜索页面和命令，Enter执行。底部“查找”定位当前正文。菜单、书架、上下文和活动面板可折叠，主题与面板偏好保留，输入法组字时不会触发保存快捷键。Skills只保存Markdown原文，不安装或执行脚本。资料中的指令不授予模型、工具或正式写入权限。

## 当前版本的边界

这是开发试用版。自动多工具编排、自动分层记忆与深层语义审核、任务级作用域规则和固定长篇性能仍有缺口；真实模型质量、最新安装器在干净Windows上的升级/卸载、签名和公开许可另需验收。请定期另存完整备份。
