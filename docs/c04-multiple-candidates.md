# C04 逐段多候选

本增量将已有 C04 任务编入持久比较组，不增加正文写入器或调度器。章节 IDEA/细纲、初稿/续写、场景/选区扩写均复用原准备、执行、修正、复核和正式采纳。正文驱动规划提案仍由 C07 负责。

## 作者操作

1. 在原有三类准备页选择候选数量（默认 1，原单候选流程；2–6 进入多候选）。预览已保存来源、范围与共同要求，再冻结。
2. 冻结产生独立任务和比较组，不外发。界面默认以本次相同模型/参数准备多份候选；API 也可把不同模型/采样配置的同输入任务编组。
3. 每个配置分别显示实际请求、目的地、输出上限和风险预算；逐条勾选确认后执行。共享原串行名额与原预算守卫，无整组发送许可，不自动重试。费用未知保持未知，不当作零费用。
4. 全部任务终态后按随机 A–F 侧展示原始候选。成功侧人工记 1–5 分；失败/取消/中断及结构化解析失败侧仅能明确确认“无可评分结果”，不能记数字分或选为胜者。
5. 全部侧保存评价后，明确揭晓身份。选择只追加选择收据并打开原任务；不会写正文、IDEA、细纲、人物或记忆。
6. 在原任务页人工修正、复核具体差异，最后正式采纳。场景仍只在冻结正文末尾插入；选区仍只替换原 Unicode 码点范围。范围外 emoji、组合字符、CRLF 和其他原文由既有精确切片机制保留。原文另存新版本、范围、IDEA/细纲、锁或配置变化时，旧执行/旧复核/旧采纳按原守卫拒绝。

## 冻结与身份

先由原准备入口保存任务，再原子编组；任务必须已保存且尚未发送，同任务不可复用到其他实验。共同输入指纹包括原目标、具体版本、上下文、来源、范围、要求及输出字符/时限约束。不同任务的请求身份、准备摘要及保存编号不当作创作来源差异；模型绑定可不同。每条原任务仍保留自己的身份、完整冻结、预算及执行许可。

准备阶段网络/页面失败可以留下未发送的独立任务，界面不会自动补发或自动取消；可从原列表查看并手动处理。同一页面中重试冻结使用原任务/分组身份；分组响应丢失时仍使用原修订号核对幂等结果。刷新页面只读取持久记录，不从浏览器存储恢复外发许可。

盲评分绑定不可变原始成功候选。揭晓后的人工修正另存原任务历史，不改原评分、原响应、原候选或原始执行耗时。选择后打开的是原任务，原任务可继续显示最新人工修正。

## HTTP 与持久化

复用 `POST /api/projects/{project}/comparisons`，新增严格分组载荷：

```json
{
  "experiment_id": "操作 UUID",
  "title": "逐段多候选名称",
  "task_kind": "scene_expansion",
  "task_ids": ["原任务 UUID 1", "原任务 UUID 2"],
  "expected_revision": 12
}
```

`task_kind` 仅为 `scene_expansion`、`chapter_planning`、`chapter_writing`；正文仅允许 `draft_chapter` / `continue_chapter`。后续复用原比较 `setup`、`execute`、`cancel`、`score`、`reveal`、`choose` 路由。外发仍需确切 `configuration_id`、`confirm_external:true` 与该请求 `request_sha256`。新组选择仅接受 `open_candidate`，不支持把用途绑定误存为旧整章改写预设。

未揭晓任务从普通工作区、原任务详情/列表隐藏，原任务修改/执行/复核/采纳入口拒绝绕过比较。不存在或跨书实验返回 404。完整导出及完整备份继续按原作者显式导出语义保存全部历史，不以盲评投影冒充备份。

仅首次编组新写升级到建议工作区/完整备份 V37。没有新增 SQL 表或工作区顶层集合；`comparison_experiments` 增加 `trial_kind=writing_candidates` 变体，原评分/揭晓/选择集合保持 append-only，A–F 只在新变体允许 2–6 侧，旧普通/文风实验仍恰为两侧。旧格式读取不落盘升级。

恢复逐行保存原状态；复制按真实命名空间映射场景/章节规划/正文任务及候选、评分/选择引用，并重算共同来源指纹。保留原请求/响应原文。重开、恢复或复制后旧 pending/running 显示中断，不能重发；仍可明确取消，完成结果可读取，正式采用仍须原流程本次会话复核。

## 验证范围

定向测试覆盖三类生产者/五种用途、同输入独立身份、三候选与六侧、不同采样、原单次确认与预算、不可评分失败、取消迟到、旧正文具体版本/范围拒绝、选择不写入、人工修正与范围外保真、实际 loopback HTTP、备份恢复及双次复制、重开不重发。另有最小合成 V1–V35 空工作区读取前后数据库字节相等检查；它不等同于全部真实历史内容逐版本重验。

Node 测试检查原三类准备页、多候选无 execute 请求、响应丢失幂等、六侧全评分揭晓、HTML 转义及中断只能取消。未跑完整桌面/Electron/打包、真实供应商、真实语义质量/遵从率或真实账单；实际命令与失败/修复日志在隔离任务交付目录 `verification.json` 中，真实付费调用 0。
