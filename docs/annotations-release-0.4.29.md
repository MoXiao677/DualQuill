# 0.4.29 本地正文批注试用

独立“正文批注”入口位于章节写作旁。选章节后，可编辑并保存正文，再对选区、当前段或整章记录原始意见。替换与删除候选先预览，再由作者明确采纳；撤销仅允许在采纳后的精确版本和正文哈希仍一致时执行。

AI 生成及独立审核采用准备、查看请求、确认外发的流程，不自动写入正文。未经真实审核不标记通过。JSON 连接配置限制、保留容量及提交不确定时的显式核对契约，见 [后端契约](annotations-backend-contract.md) 和 [界面说明](annotations-ui-0.4.29.md)。

修改集中在 application/annotations.py、ui/static/annotations.js、app.js、style.css、ui/server.py 和 desktop/security.cjs；应用版本元数据更新为 0.4.29。正文仍使用 NovelService 保存与既有版本历史。批注使用独立 sidecar，不修改工作区结构版本。

协调方实际完成的验证：

- 隔离虚构书中检查 Unicode 选区、持久化重读、跨书拒绝、精确候选预览、业务保存、幂等接受、撤销、过期来源、后续编辑保护、已确认章节授权和正文已保存但批注回执失败的显式恢复。
- 隔离 LocalServer 通过鉴权 HTTP 执行创建、手工候选、接受与撤回，核对正文前后结果；列表读取未发送模型请求。
- Node 调用实际导出的选区函数，核对 CRLF、LF、单独回车、emoji、当前段、整章、空章、不一致编辑区及截断代理对的拒绝。
- Python AST、Node 模块及桌面安全文件语法、git diff --check、独立目录构建、资源清单、源码 SHA-256 和 ASAR 文件一致性检查。
